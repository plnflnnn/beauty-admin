# Beauty Admin – Appointment Management App

A beauty salon admin dashboard for managing customer appointments with a calendar-based interface.  
This project was created to **practice and strengthen TypeScript skills**.

---

## 🖥 Overview

**Beauty Admin** allows salon staff to:

- Create new customer appointments
- View upcoming and past appointments
- Cancel appointments
- Track remaining time until an appointment
- Manage appointment history

The UI simulates a real-world beauty salon admin panel.

---

## 🛠 Tech Stack

**Frontend**

- React 18
- TypeScript
- React Router

**Libraries**

- `react-calendar` – calendar view
- `dayjs` – date & time handling
- `react-transition-group` – UI transitions

**Mock Backend**

- `json-server` (local REST API)
